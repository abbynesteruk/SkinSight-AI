
# SkinSight Notebooks

This directory contains the Jupyter notebooks used to develop and evaluate SkinSight.

## Notebooks

1. `01_data_exploration.ipynb` - Exploring the HAM10000 dataset.
2. `02_data_preprocessing.ipynb` - Preparing images for training.
3. `03_model_training.ipynb` - Training the MobileNetV2 model.
4. `04_model_evaluation.ipynb` - Evaluating model performance.
